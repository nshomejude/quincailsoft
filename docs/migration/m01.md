# M01 migration — sales documents, quotations and returns

Authority: ARCHITECTURE.md §§2.2–2.3,3,7,8,13,32,37–39. Java25/SpringBoot4/JPA/PostgreSQL18; no Python delegation.

## Implemented workflows

- Immediate zero-tax sale posting now issues its immutable numbered invoice in the stock/journal/idempotency/outbox transaction. A deferred database constraint rejects POSTED sales without a matching invoice. Missing issuer configuration fails the entire posting; it creates neither stock nor finance facts nor consumed document numbers.
- Scoped document issuer settings with revision checks; per-tenant/company/branch/kind/year/series serialized number allocation. Snapshot freezes source amounts/lines, issuer identity, actor and template version, plus SHA256. Database facts cannot be edited/deleted. Current issuer changes do not alter historical originals.
- Scoped document list/detail and escaped EN/FR A4 HTML print view; explicit COPY watermark does not mutate or reissue the original. Reprints do not post stock/finance again. Credit notes reference the original sale.
- Typed quotation draft with catalog pricing; issue numbered snapshot; accepted quotation conversion to one linked sale draft. Immutable operation replay returns the original result. Changed prices, expired quotations, nonzero tax and unsupported fractional-FCFA conversion reject rather than changing the quoted amount silently.
- Typed sellable customer return draft with inspection evidence and original sale quantity/revenue/cost valuation; independent operator approval; posting checks aggregate prior returns. Physical stock reacquisition, customer receivable/customer-credit split, balanced revenue/COGS reversal, original-sale-linked numbered credit note, idempotency and outbox commit together. No cash or provider refund is implied.

## Endpoints and permissions

- `/api/v1/documents` list and `/{id}` detail, `/{id}/print?copy=true`: documents:read.
- `/api/v1/documents/settings` GET/PUT: documents:configure. GET unconfigured returns blank version0; posting requires configured issuer fields.
- `/api/v1/quotations` list/detail/draft, `/{id}/issue`, `/{id}/convert`: quotations:read/write/issue.
- `/api/v1/returns` list/detail/draft, `/{id}/approve`, `/{id}/post`: returns:read/write/approve/post.
- Mutation operations use UUID Idempotency-Key matching operationId, global X-Request-ID and record version where applicable. Document settings use versioned configuration save.

Current HTML is a bounded immutable A4 preview, not fiscal accreditation.

- Damaged/quarantine returns, exchanges, supplier returns, impairment, discount/tax allocations, rounding policies, credited-balance spending and actual cash/provider refunds remain incomplete. Return partial amounts must currently be integral FCFA exactly representable from original valuation.
- Sales tender/credit-limit policy, tax engine and full offline/print recovery gates remain open. No full module or production certification is claimed.
